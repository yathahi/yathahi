# Contributing to Yathahi

Thank you for your interest in contributing! We welcome bug fixes, new features, documentation improvements, and ideas from the community.

## 1. Copyright Assignment & Recognition

To keep **Yathahi** under a single, unified **Apache License 2.0** and protect the long-term stewardship of the project:

* **One-Click Agreement:** Before your Pull Request can be merged, you must sign our **Individual Contributor Copyright Assignment Agreement**. When you open a Pull Request, our automated bot will post a link where you can review and sign it digitally with one click.
* **Keep Your Own Rights:** Under the agreement, you receive an immediate, perpetual, worldwide, royalty-free grant-back license to use, modify, and distribute your own contributed code for any purpose.
* **Full Public Credit:** Your authorship is always preserved in our Git commit history, release notes, and `CONTRIBUTORS.md` file.

## 2. How to Submit a Contribution

1. **Fork the Repository:** Click the **Fork** button at the top right of the main repository page to create your own copy.
2. **Clone Your Fork:**
   ```bash
   git clone https://github.com/yathahi/yathahi.git
   cd yathahi
   ```
3. **Create a New Branch:** Always make your changes on a dedicated branch rather than `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make Your Changes & Commit:** Write clean, well-tested code and commit it using your verified GitHub email so your profile gets full credit:
   ```bash
   git add .
   git commit -m "Describe your change clearly"
   ```
5. **Push to Your Fork:**
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request:** Go to your fork on GitHub, click **Contribute** -> **Open pull request**, and submit it against the `main` branch of `[YourOrg]/[YourRepo]`.
7. **Sign the CLA:** Follow the link posted by the bot in your Pull Request comments to complete the one-click digital signature.

## 3. Keeping Your Fork Up to Date

Before starting new work, sync your fork with the latest changes from the main repository by clicking **Sync fork** -> **Update branch** on your fork's GitHub page, then run `git pull origin main` in your terminal.
