# Security Policy

## Reporting a Vulnerability

Security is a core design principle of **Yathahi**. If you discover a security vulnerability, please **do not** open a public GitHub Issue.

Instead, report it privately so we can investigate and release a fix before public disclosure:

* **Email:** yathahi.official@gmail.com
* **GitHub Private Vulnerability Reporting:** Use the **Security → Advisories → Report a vulnerability** tab on this repository (if enabled).

Please include:
1. A clear description of the vulnerability and potential impact.
2. Steps or a minimal proof-of-concept to reproduce the issue.
3. Affected components (`Entry`, `Core`, `Engine`, or `library`).

We will acknowledge your report within 48 hours and keep you updated as we work on a resolution.
